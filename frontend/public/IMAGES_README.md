# 📁 Placement des Images

## Emplacement requis

Placez vos fichiers directement dans le dossier **`public/`** :

```
frontend/
└── public/
    ├── logo.png       ← PLACEZ LE LOGO ICI
    └── favicon.png    ← PLACEZ LE FAVICON ICI
```

## Fichiers requis

### logo.png
- **Emplacement :** `/frontend/public/logo.png`
- **Chemin dans le code :** `/logo.png`
- **Dimensions recommandées :** 200x80px
- **Format :** PNG avec fond transparent

### favicon.png  
- **Emplacement :** `/frontend/public/favicon.png`
- **Chemin dans le code :** `/favicon.png`
- **Dimensions :** 32x32px ou 64x64px
- **Format :** PNG

## Vérification

Après avoir ajouté les fichiers :
1. Actualisez le navigateur (F5)
2. Le logo devrait s'afficher sur toutes les pages
3. Le favicon devrait apparaître dans l'onglet du navigateur

## Note

Dans Vite, les fichiers du dossier `public/` sont servis à la racine.
Pas besoin de redémarrer le serveur.
